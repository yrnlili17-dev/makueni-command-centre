# Phase 6 ZIP D – Executive Dashboard

Adds a strategic operations dashboard for campaign leadership.

Features
- Executive KPI cards
- Live operational alerts
- Threat heat map placeholder
- Response SLA monitor
- Team workload panel
- Approval backlog
- Platform performance comparison
- One-click export hooks
- Local-data mode (no API keys)

Install

```bash
unzip Phase6-Zip-D-Executive-Dashboard.zip -d phase6-zip-d
node phase6-zip-d/phase6-zip-d-dashboard/install-phase6-zip-d.mjs
```
